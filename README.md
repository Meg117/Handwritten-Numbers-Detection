# Handwritten-Numbers-Detection Deep Learning, CNN, Keras, Tkinter

This repository contains reproducible code  for a trained convolutional neural network (CNN) for
image-based pattern recognition, using the MNIST dataset of handwritten digit images (60,000 training / 10,000 testing samples)
to classify visual patterns with high accuracy.

## Overview
The project contains trained a convolutional neural network (CNN) for image-based pattern recognition, 
using the MNIST dataset of handwritten digit images (60,000 training / 10,000 testing samples) to classify
visual patterns with high accuracy.

## Data
- Source: MNIST
